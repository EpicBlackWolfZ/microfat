# Formal Verification Ledger

This ledger tracks every formal verification obligation across `microfat` as mandated by [ADR-0012](../adr/ADR-0012-engineering-governance-and-docs-as-code.md). Every entry links a named `LAW-*` invariant to its production or model source, pinned verifier in [`.config/tool-versions.env`](../../.config/tool-versions.env), reproducible Task target, CI/release gate step, trusted assumptions, and regression sensitivity test.

## Cross-Language Conformance & Rust Quality Gates

To link separate Lean 4 specifications directly to shipped Go and Rust implementations:

- **Canonical Vector Generator**: [`formal/lean/Microfat/Conformance.lean`](../../formal/lean/Microfat/Conformance.lean) executes the verified Lean 4 models to emit deterministic golden vectors at [`formal/conformance/vectors.json`](../../formal/conformance/vectors.json). Drift is rejected on every PR by `task verify-lean` (`ci.yml:lean-proof`, `release.yml:lean-proof`).
- **Go Conformance Suite**: [`internal/conformance/conformance_test.go`](../../internal/conformance/conformance_test.go) executes every `FormatV2`, `Microarch` (AMD64/ARM64 DAG & policy selection), and `CgroupMath` vector against production Go packages under `-race`.
- **Rust Conformance & Quality Gates**: [`experiments/v3lab/rust-stub/src/conformance_tests.rs`](../../experiments/v3lab/rust-stub/src/conformance_tests.rs) executes every Lean vector (plus `ElfFilter`) under `task test-rust` (`ci.yml:rust-test`, `release.yml:rust-test`), while `task lint-rust` (`ci.yml:rust-lint`, `release.yml:rust-lint`), `task vuln-rust` (`CARGO_AUDIT_LINUX_AMD64`, `CARGO_DENY_LINUX_AMD64`, `ci.yml:rust-vuln`, `release.yml:rust-vuln`), `task coverage-rust` (`CARGO_LLVM_COV_LINUX_AMD64`, `>= 95%`, `ci.yml:rust-coverage`, `release.yml:rust-coverage`), and `task test-rust-stub-e2e` (`ci.yml:rust-e2e`, `release.yml:rust-e2e`) gate every code PR and release tag.
- **Standards Conformance Tracking**: See the [Security Standards Compliance Matrix](../security-standards-compliance.md) for how these formal assurance gates map into NIST SSDF, NIST SP 800-53, EU CRA, and downstream compliance evidence.

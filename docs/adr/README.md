# Architecture Decision Records (ADRs)

This directory is the canonical index of Architecture Decision Records for `microfat`, established under [ADR-0012](ADR-0012-engineering-governance-and-docs-as-code.md).

`ADR-0001` remains at its original path ([`docs/design/adr-0001-formal-verification-and-v3-lab.md`](../design/adr-0001-formal-verification-and-v3-lab.md)) to preserve immutable historical references; all subsequent ADRs use `docs/adr/ADR-NNNN-<slug>.md`. Use [the ADR template](TEMPLATE.md) when authoring new ADRs.

> **Backfill status (`v0.5.0`):** Retroactive ADRs `ADR-0002` through `ADR-0011` (`v0.1.0`–`v0.4.1`) and `v0.5.0` architectural ADRs (`ADR-0013`, `ADR-0014`) have been completed under [#526](https://github.com/EpicBlackWolfZ/microfat/issues/526). Normative specifications (`SPEC-0001`–`SPEC-0010`) and formal proof expansions are tracked in [#527](https://github.com/EpicBlackWolfZ/microfat/issues/527), [#528](https://github.com/EpicBlackWolfZ/microfat/issues/528), and [#529](https://github.com/EpicBlackWolfZ/microfat/issues/529).

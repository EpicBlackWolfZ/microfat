# Matched dedup cost diagnostic

Supplement the frozen size screen without changing its gates. The screen
identified one-base using v2 and the shared Gear CDC container as the two
candidate representations with the strongest complete artifact sizes. Fix these
two arms, all four Go families and both stripping profiles before collecting
cost observations. The synthetic boundary inputs remain byte-exactness
controls in the size report.

Packing is one controlled fresh process per family, profile and arm. Collect
the balanced control and both best controls along with the two candidate
representations at each encoding level. Compare the candidate's inventory,
encoding and write against the production Pack call. The candidate writes
its alternate container only, so the timing omits production launcher copying
and atomic publication. Match byte sizes and SHA-256 to the full size run.
The cgroup budget is 4 GiB for these commands. A single observation does not
support an inference about production Pack regressions.

Materialization uses the stronger production best control chosen by complete
artifact bytes before these timings. For each of the four families and two
profiles use the non-base v3 target. In separate fresh processes and cgroups
load that target from either the complete production artifact, one-base v2,
or shared CDC, then write to a real new sealed memfd or a fresh private
production cache directory. Read controlled candidate inputs with a read-only
file mapping. Reuse the existing bounded offline reconstruction and the
production cache materialization and memfd seal APIs. Verify the output digest
before applying seals or publishing the cache descriptor. Exclude process
startup and application exec from the subphase timer. Capture whole worker
process CPU and peak RSS independently. Capture cgroup memory.peak, events,
memory.max, memory.swap.max and cpu.max from a fresh transient scope before
it disappears. Budget 256 MiB and four cores with swap unavailable for all
materialization scopes. This limit probes the frozen 256 MiB screening
budget, which originally described logical buffers. These measures include
different things and are not interchangeable.

Perform seven consecutive blocks per cell with fixed arm rotation. There is no
page cache eviction. The disk cache destination is empty for each attempt;
the input page cache is warm or unspecified. Pin Go 1.27.4, GOMAXPROCS=4, GC
defaults, and constrain GOMEMLIMIT to 2 GiB when packing and 192 MiB during
materialization, with the respective cgroup memory ceiling as the hard limit.
The collector preserves attempts and errors without retrying any observation.
Report ratios by mode and stratum, stage and process CPU/RSS, and cgroup
high-water bounds. Treat all outcomes as descriptive diagnostic observations.
Neither whole-process launch, fallback admission, warm-cache production
performance nor supported execution of the experimental container is measured.
